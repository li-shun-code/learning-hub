# 数据结构与算法学习 · 课程大纲

> 这份大纲定义了完成本课题后你将掌握的所有能力。
> 学习深度：标准
> 文档数量因人而异，但掌握内容不打折扣。

## 核心掌握项

完成本课题后，你将能够：

### 模块一：复杂度分析（地基）

- [x] 能说明为什么需要复杂度分析，而不只靠事后统计法
- [x] 能用大 O 表示法推导简单代码的渐进时间复杂度，并解释为何忽略常数、低阶项与系数
- [x] 能用加法法则与乘法法则分析多段、嵌套代码的复杂度
- [x] 能识别 O(1)/O(logn)/O(n)/O(nlogn)/O(n²) 五类常见量级，并分析代码的空间复杂度

### 模块二：线性数据结构

- [x] 能解释数组连续存储带来的随机访问优势与插入删除代价，并给出对应复杂度
- [ ] 能手写链表基本操作，并无 bug 实现反转链表、求中间结点等经典题目
- [ ] 能用栈与队列实现浏览器前进后退、括号匹配等具体问题
- [ ] 能实现一个用拉链法解决冲突的散列表，并说明装载因子与扩容的作用

### 模块三：非线性数据结构

- [ ] 能区分满二叉树与完全二叉树，并实现二叉树的前/中/后序与层序遍历
- [ ] 能实现小顶堆，并说明堆在优先级队列、TopK、中位数三类场景中的用法
- [ ] 能用邻接矩阵与邻接表表示图，并实现 BFS 与 DFS

### 模块四：补充结构与选型判断

- [ ] 能解释跳表的多层索引原理，并说明 Redis 有序集合为何选它
- [ ] 能说明 Trie 的结构特点与搜索提示、敏感词过滤等应用场景
- [ ] 面对一个具体场景，能在数组/链表/散列表/树/堆之间做出选择并给出理由

## 不在本课题范围内

本课题面向初学者，以下进阶主题暂不涵盖：

- 红黑树、B+ 树的实现
- BM / KMP / AC 自动机等复杂字符串匹配
- 哈希算法在分布式系统的应用、拓扑排序、最短路径、A*
- 概率统计、向量空间、并行算法等数学与系统专题
- LeetCode 题量堆砌：本课以"理解原理 + 手写经典题"为主，不追求刷题数量
- 贪心 / 分治 / 回溯 / 动态规划四大算法思想：可作为后续独立专题

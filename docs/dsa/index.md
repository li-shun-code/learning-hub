# 图解数据结构与算法

> 这是[学习中心](/)的一个模块。想看其他主题，请回到[站点首页](/)，或查看[大模型应用开发](/llm/)。

用**图解 + Python 代码**把数据结构与算法讲清楚：先看懂「它长什么样、怎么动起来」，再落到代码，最后刷题巩固。

## 为什么「图解」？

数据结构和算法的难点往往不是代码本身，而是**看不见过程**：链表指针怎么跳、递归怎么一层层展开、动态规划的表格怎么填。图解把这些过程画出来，让抽象变直观。

本站借鉴了 [Hello 算法](https://www.hello-algo.com/)（500+ 动画图解）和 [小林 coding](https://www.xiaolincoding.com/)（图解 + 通俗讲解）的思路，但用中文笔记 + Python 实现 + 字符示意图的形式，方便你边看边敲。

## 学习路线

建议按下面的顺序学，先数据结构、后算法，每一步都配 Python 实现：

### 第一阶段：基础与线性结构

1. [复杂度分析](/dsa/complexity) —— 学会用 Big-O 衡量好坏
2. [数组与链表](/dsa/array-linked-list) —— 最基础的两种存储方式
3. [栈与队列](/dsa/stack-queue) —— 受限的线性结构
4. [哈希表](/dsa/hash-table) —— 为什么查找能接近 O(1)

### 第二阶段：非线性结构

5. [树与二叉树](/dsa/tree) —— 层次关系的表示
6. [堆与优先队列](/dsa/heap) —— 高效取最值
7. [图](/dsa/graph) —— 复杂关系网络

### 第三阶段：核心算法思想

8. [递归与分治](/dsa/recursion) —— 把大问题拆小
9. [排序](/dsa/sorting) —— 经典排序算法图解
10. [查找与二分](/dsa/binary-search) —— 有序数据的高效查找
11. [双指针与滑动窗口](/dsa/two-pointers) —— 数组/字符串高频技巧
12. [贪心算法](/dsa/greedy) —— 每一步都选当前最优
13. [动态规划](/dsa/dynamic-programming) —— 记住子问题答案
14. [回溯与搜索](/dsa/backtracking) —— 穷举 + 剪枝

## 怎么学效果最好？

- **先画图，再写代码**：用一个小例子（比如 5 个元素）手动模拟整个过程。
- **手敲一遍**：看懂不等于会写，照着思路自己实现。
- **刷题巩固**：学完一个结构，去 LeetCode 做 2–3 道对应难度的题。
- **讲出来**：试着把算法讲给别人（或 AI）听，讲不通的地方就是没懂的地方。

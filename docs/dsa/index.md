# 图解数据结构与算法

> 这是[学习中心](/)的一个模块。想看其他主题，请回到[站点首页](/)，或查看[大模型应用开发](/llm/)。

一份系统、完整的中文讲义：**按经典课程顺序的 56 讲正文**，配合**可交互的动画图解**，帮你把抽象的数据结构与算法「看明白、跑起来、写得出」。

## 这个模块有什么？

- 📖 **56 讲完整正文**：从复杂度分析、线性结构，到树、图、排序、查找，再到贪心/分治/回溯/动态规划与实战剖析，循序渐进。
- 🎬 **交互动画图解**：28 讲配有可交互动画——支持播放/暂停、单步、调速、换数据，边读边对照每一步发生了什么。动画集中在正文开头，形成「先建立直觉，再读推导」的节奏。
- 🖼️ **原文配图本地化**：全部配图随站点一起加载，离线也能看。
- 🐍 **教学与实现并重**：正文以提问驱动，配合代码与图示，既讲「怎么做」，也讲「为什么这样设计」。

## 学习路线

左侧「图解数据结构与算法 · 56 讲」按讲次顺序编排，建议从头读起；每讲标题就是那一讲要回答的核心问题。

### 第一阶段 · 打基础（1–17 讲）
复杂度分析 → 数组/链表 → 栈/队列 → 递归 → 排序 → 二分查找 → 跳表。
重点是建立**复杂度意识**与**线性结构手感**；复杂度分析是后面所有内容的地基。

### 第二阶段 · 非线性结构与查找（18–36 讲）
散列表 → 哈希算法 → 二叉树/红黑树 → 递归树 → 堆 → 图与 BFS/DFS → 字符串匹配 → Trie/AC 自动机。
重点是理解**不同结构的取舍**：为什么有了散列表还需要树，为什么工程中常用红黑树和堆。

### 第三阶段 · 核心算法思想（37–51 讲）
贪心 → 分治 → 回溯 → 动态规划 → 拓扑排序/最短路径 → 位图/概率统计/向量空间 → B+ 树/索引/并行算法。
这部分是**面试与实战的分水岭**，建议每学完一种思想，手写 2–3 道题巩固。

### 第四阶段 · 综合实战（52–56 讲）
剖析 Redis、搜索引擎、Disruptor、鉴权限流背后的数据结构，以及短网址系统的设计。
把零散知识串起来，看看真实系统怎么选用这些结构。

## 怎么学效果最好？

- **先跑动画，再读正文**：动画给你直觉，正文给你严谨推导，两者互相印证。
- **手敲代码**：看懂不等于会写，照着正文的思路自己实现一遍。
- **每讲一道思考题**：正文末尾的思考题先自己想，再点开折叠的答案对照。
- **讲出来**：试着把算法讲给别人（或 AI）听，讲不通的地方就是没懂的地方。

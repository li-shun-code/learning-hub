# 贪心算法

> 贪心算法在每一步都做出当前看起来最好的选择，希望最终得到全局最优。它简单高效，但**并非对所有问题都成立**。

<VisGreedy />

## 一、核心思想

```text
每一步：选择当前最优（局部最优）
       ↓
不回头、不撤销
       ↓
期望累积成全局最优
```

贪心成立的前提是问题具有「**贪心选择性质**」：局部最优能导致全局最优。这需要证明，不能凭感觉。

## 二、经典例题：区间调度

选择最多数量的互不重叠区间。

```text
区间: [1,3], [2,4], [3,5], [0,6], [5,7], [8,9]

策略：按「结束时间」排序，每次选结束最早的兼容区间

排序后: [1,3], [2,4], [3,5], [0,6], [5,7], [8,9]
选 [1,3]（结束最早）→ 下一个起点 ≥3 的有 [3,5] → 选 [3,5]
→ 下一个起点 ≥5 的有 [5,7] → 选 [5,7] → [8,9]
结果: [1,3], [3,5], [5,7], [8,9] 共 4 个 ✓
```

```python
def interval_schedule(intervals):
    # 按结束时间升序排序
    intervals.sort(key=lambda x: x[1])
    count = 0
    last_end = float('-inf')
    for start, end in intervals:
        if start >= last_end:      # 与已选区间不重叠
            count += 1
            last_end = end
    return count

print(interval_schedule([(1,3),(2,4),(3,5),(0,6),(5,7),(8,9)]))  # 4
```

::: tip 为什么按结束时间？
结束越早，给后面的区间留下的空间越大。如果按开始时间或区间长度排，可能选到「跨度大」的区间导致后续选择变少。
:::

## 三、经典例题：找零钱

用最少的硬币凑出金额（硬币面额 1、5、10、25）。

```text
凑 63：
25+25+25 = 75 > 63，选 2 个 25 = 50
剩 13，选 1 个 10 = 60
剩 3，选 3 个 1
共 2+1+3 = 6 枚 ✓
```

```python
def coin_change_greedy(coins, amount):
    coins.sort(reverse=True)     # 从大到小
    count = 0
    for coin in coins:
        while amount >= coin:
            amount -= coin
            count += 1
    return count

print(coin_change_greedy([1, 5, 10, 25], 63))   # 6
```

::: danger 贪心何时失效？
如果硬币面额是 [1, 5, 11]，凑 15：
- 贪心：11 + 1+1+1+1 = 5 枚
- 最优：5 + 5 + 5 = 3 枚 ❌

这时贪心不是最优解，必须用[动态规划](/dsa/dynamic-programming)。**判断贪心是否适用是难点**。
:::

## 四、更多经典贪心问题

| 问题 | 贪心策略 |
|---|---|
| 买卖股票 II | 只要明天涨就今天买、明天卖（累加所有正差值） |
| 分发饼干 | 小饼干先给胃口小的孩子 |
| 加油站 | 从油量不够的下一站重新开始 |
| Huffman 编码 | 每次合并频率最小的两棵树（配合[堆](/dsa/heap)） |
| Dijkstra 最短路 | 每次扩展距离最近的未访问节点 |

## 五、贪心 vs 动态规划

| | 贪心 | 动态规划 |
|---|---|---|
| 决策 | 当前最优，不回头 | 考虑所有子问题，选择最优组合 |
| 效率 | 通常 O(n) 或 O(n log n) | 通常 O(n²) 或更高 |
| 适用 | 需满足贪心性质 | 更通用，但有重叠子问题 |
| 难度 | 证明难，代码简单 | 状态设计难 |

## 六、图解：贪心的「不可逆」

```text
贪心:  A → B(选当前最好) → C → 结果    [一条路走到底]
DP:    A → B1 ─┐
       A → B2 ─┼→ 比较所有可能 → 最优结果  [穷举 + 记忆]
       A → B3 ─┘
```

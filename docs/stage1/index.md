# 阶段 1 · Python 与工程基础

> **目标**：打牢 Python 与工程地基，能熟练写脚本和接口服务。
> **建议时长**：30–45 天（零基础），有基础可快速过一遍。
> **产出**：一个带数据校验和简单存储的 FastAPI 小服务。

## 为什么这一阶段很重要

AI 应用开发说到底是**软件开发**。没有扎实的编程和工程基础，后面学 API 调用、RAG、Agent 都会很吃力。好消息是：**零基础不需要把 Python 学得很深，能熟练写脚本和接口服务就够了**。

这一阶段我们按「先跑起来 → 学语法 → 做项目」的顺序推进，每学一个知识点都动手敲代码验证。

## 学完这一阶段，你应该能

- [ ] 独立搭建干净的 Python 开发环境，知道为什么要用虚拟环境
- [ ] 熟练使用列表、字典、函数、类写出结构清晰的小脚本
- [ ] 正确读写文件与 JSON，处理常见异常
- [ ] 用 FastAPI 写出带 Pydantic 校验的 HTTP 接口
- [ ] 用 Git 管理代码，用 `.env` 管理配置，能写清楚 README

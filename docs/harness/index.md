## 如何使用学习助手

1. 打开任意一章，点击右下角悬浮的 💬 按钮打开学习助手，再点 **⚙ 模型配置**。
2. 填写 OpenAI 兼容的 `chat/completions` 接口地址、API Key 和模型名（如 `gpt-4o-mini`）。也支持自建服务、Ollama、One API 等，前提是接口允许浏览器跨域访问。
3. 保存后即可提问，例如“用一句话总结本课核心观点”“本课有哪些关键概念”。助手只依据当前页面正文回答，不会编造正文之外的内容。

# 2. 工具选择与环境

AI 编程工具大致分两类：**IDE 内嵌助手**（在编辑器里用）和 **命令行 / 独立 Agent**（能自己动手改多个文件、跑命令）。新手建议各选一款配合用。

## 一、IDE 内嵌助手

### Cursor

- 基于 VS Code 的 AI 编辑器，Tab 补全、内联编辑、Chat 都很顺手。
- 适合：日常写代码、快速改小段代码、边写边问。
- 上手：官网下载安装 → 登录 → 在设置里配置模型 → 打开一个文件夹直接开始。

### GitHub Copilot

- 老牌补全工具，兼容性好，企业场景常见。
- 适合：已经习惯 VS Code / JetBrains 的人。

### VS Code + 插件

如果你不想换编辑器，VS Code 装 Copilot、Codeium、通义灵码等插件也能达到类似效果。

::: tip 建议
新手优先选 **Cursor**（或 VS Code + 一款 AI 插件），因为它和写代码的动作结合最紧，学习成本最低。
:::

## 二、命令行 / 独立 Agent

这类工具能读你的整个项目、自己改多个文件、跑测试命令，适合较大的任务。

| 工具 | 特点 | 适合场景 |
|---|---|---|
| Claude Code | 命令行 Agent，擅长长任务、代码库级修改 | 复杂功能、跨文件重构 |
| Codex CLI | OpenAI 的命令行编码 Agent | 与 OpenAI 生态配合 |
| 各类国产 Agent | 通常对中文支持好、接入国内模型方便 | 国内网络环境、成本敏感 |

::: warning 注意
命令行 Agent 会**真的修改你的文件、执行你的命令**。第一次用时，先在一个无关的测试文件夹里试，确认它做了什么，别直接在重要项目上跑。
:::

## 三、环境准备清单

无论选哪款工具，先把基础环境装好：

1. **Python 解释器**：官网下载 3.10+ 稳定版，安装时勾选「Add Python to PATH」。验证：`python --version`。
2. **代码编辑器**：Cursor 或 VS Code。
3. **终端**：Windows 用 PowerShell 或 Windows Terminal；macOS / Linux 用自带终端。
4. **Git**：`git --version` 能输出版本号即可（后面部署站点要用到）。
5. **一个测试文件夹**：比如 `E:\code\test-ai\`，专门用来练手，随便让 AI 改。

## 四、第一次对话：怎么开口

别一上来就说「帮我做个大项目」。从具体的小任务开始，例如：

```text
请写一个 Python 脚本 greet.py：
- 定义一个函数 greet(name)，返回 "你好，{name}！欢迎学习大模型应用开发。"
- 在脚本底部用 __main__ 判断，调用 greet("小明") 并打印结果
- 加上必要的注释
写完后请逐行解释这段代码在做什么。
```

注意这段指令的结构：**任务（写什么）+ 约束（具体要求）+ 附加要求（解释）**。这就是一个好指令的雏形。

## 五、安全与成本小贴士

- **密钥**：API Key 不要写死在代码里，用 `.env` 文件管理，并把 `.env` 加进 `.gitignore`。
- **成本**：不同模型价格差异很大，练手时用便宜的模型或本地模型即可。
- **审查**：AI 说「已经测试通过」不代表真的通过，自己跑一遍最稳。

# 大模型应用开发模块

> 这是学习中心的一个模块。想看其他主题，请回到[站点首页](/)，或查看[图解数据结构与算法](/dsa/)。

一条按依赖关系排列的路线：**先应用、后原理**，每一步都有产出。

## 在线学习路线

- **[完整九阶段路线](/llm/roadmap)**：从 AI 工具、Python 工程，到提示词、RAG、Agent、评测部署。
- **[阶段 0 · AI 编程工具上手](/llm/stage0/)**：3–7 天，用 AI 辅助写完一个小工具。
- **[阶段 1 · Python 与工程基础](/llm/stage1/)**：30–45 天，能写脚本和 FastAPI 接口。

## 学习原则

1. **先把它当黑盒用起来**，做出项目建立直觉，再回头拆开看原理。
2. **每个阶段都要有产出**：一个小工具、一个接口、一个能演示的应用。
3. **善用 AI 工具**：让 AI 解释概念、审查代码，但核心代码自己写。

## 阶段总览

| 阶段 | 主题 | 时长 | 产出 |
|---|---|---|---|
| 0 | AI 编程工具上手 | 3–7 天 | 用 AI 辅助写完一个小工具 |
| 1 | Python 与工程基础 | 30–45 天 | 能写脚本 + FastAPI 接口 |
| 2 | 大模型认知 | 5–7 天 | 能讲清 token、上下文、能力边界 |
| 3 | API 调用开发 | 7–10 天 | 一个能对话的小应用 |
| 4 | 提示词工程 | 7–10 天 | 一套可复用的提示词模板 |
| 5 | RAG 检索增强 | 15–20 天 | 一个带知识库的问答应用 |
| 6 | Agent 智能体 | 20–30 天 | 一个能调用工具的助手 |
| 7 | 评测、可观测与安全 | 10–15 天 | 一套评测与防护方案 |
| 8 | 部署、微调与原理 | 选学 20–40 天 | 上线服务 / 微调模型 / 读懂 Transformer |

完整说明见[学习路线](/llm/roadmap)。
